# favo76 — logos

Arquivos da marca favo76, sem fundo (transparentes).

- `svg/` vetores, para editar ou imprimir
- `png/` imagens transparentes

Cores: Mel `#F8A000` · Tinta `#141413` · Papel `#F4F1EA`

Nomes: `fundo-escuro` = versão clara, para usar sobre fundo escuro. `fundo-claro` = versão escura, para usar sobre fundo claro.
